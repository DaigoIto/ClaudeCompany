# リード台帳テンプレート

営業・クライアント獲得を行う事業向けのリード管理台帳。
オンボーディング時にQ1の内容が営業・リード管理を含む場合に `.company/leads.md` として生成する。

---

## テンプレート

````markdown
# リード台帳

最終更新: {{CREATED_DATE}}

## ステータス定義

| ステータス | 意味 |
|---|---|
| 🎯 アプローチ予定 | 未接触・送信準備中 |
| ✉️ 返信待ち | 送信済・返信なし |
| 💬 商談中 | 返信あり・交渉中 |
| ✅ 成約 | 契約・受注済み |
| ❌ 見送り | 対象外・タイミング不一致 |

---

## アクティブリード

| ID | 企業・相手名 | 経路 | ステータス | 最終アクション | 備考 |
|---|---|---|---|---|---|
| A-01 | | | 🎯 アプローチ予定 | {{CREATED_DATE}} | |

---

## 見送り

| ID | 企業・相手名 | 見送り理由 |
|---|---|---|
| Z-01 | | |

---

## 集計

- アクティブ: 0件
- 返信待ち: 0件
- 商談中: 0件
- 成約: 0件
- 見送り: 0件
````

---

## 運用ルール

- IDは `A-XX`（アクティブ）、`Z-XX`（見送り）で管理
- 同じ企業の重複登録は禁止
- ステータス変更時は「最終アクション」日付も更新する
- 見送りリードは削除せず Z-XX に移動して理由を記録する
