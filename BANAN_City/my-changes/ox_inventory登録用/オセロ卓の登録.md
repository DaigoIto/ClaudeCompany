# アイテム「オセロ卓」の登録 (サーバー管理者向け)

このフォルダは kani-othello 本体では読み込まれません。インベントリ側に1回だけ登録してください。

## ox_inventory (Qbox の標準)
1. `ox_inventory/data/items.lua` の `return {` の中に、次を追加
   ```lua
   ['othello_table'] = {
       label = 'オセロ卓',
       weight = 5000,
       stack = false,
       close = true,
       consume = 0,
       description = '使うと目の前にオセロの卓を置く。卓の横で G(またはAltの目)で片付け',
       server = { export = 'kani-othello.othello_table' },
   },
   ```
2. 画像(任意): `othello_table.png` を `ox_inventory/web/images/` に置く(無くても動く。五目並べの `gomoku_set.png` を流用してもよい)
3. サーバー再起動(または ox_inventory と kani-othello を restart)
4. 確認: 管理者で `/giveitem <自分のID> othello_table 1` → インベントリから使う

## QBCore (qb-inventory) / ESX の場合
- QBCore: `qb-core/shared/items.lua` に `othello_table` を追加(`useable = true`)。画像は qb-inventory の images へ
- ESX: `items` テーブルに `othello_table` を追加
- どちらも「使う」の登録は kani-othello が自動で行う

## 補足
- アイテムは使っても減りません(卓は持ち主のログアウト・切断・サーバー停止で自動的に片付く)
